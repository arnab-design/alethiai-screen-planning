# AlethiAI Screen Planning

A React application for viewing and managing AlethiAI product screens and features.

## Features

- Interactive table displaying all 24 screens
- Search functionality across screen names, purposes, features, users, and notes
- Module filtering (Module 1-5)
- Expandable rows for better readability
- Responsive design

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
